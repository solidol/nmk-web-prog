# Спорідненість синтаксису PHP з мовами C, C++, C#, Java, JavaScript

## Мета

Розпізнавати спільні синтаксичні конструкції та відмінності їхньої семантики, щоб уникати механічного перенесення коду між мовами. Самостійна робота — 2 год.

## Теоретичний матеріал

PHP належить до мов із C-подібним синтаксисом. Фігурні дужки позначають блоки, круглі дужки обрамляють умови та аргументи, крапка з комою завершує більшість простих інструкцій. Конструкції `if`, `else`, `for`, `while` впізнавані для розробників C, C++, C#, Java та JavaScript. Проте зовнішня схожість не гарантує однакового результату виконання.

У PHP ім'я змінної починається з `$`. Для звичайного присвоєння не потрібно попередньо оголошувати її тип: значення може змінювати тип під час виконання. У C, C++, C# і Java тип змінної визначається оголошенням або виводиться під час компіляції. JavaScript також допускає значення різних типів у змінній, але використовує власні правила оголошення та області видимості.

Оператор `=` присвоює значення. У PHP `==` порівнює з можливими перетвореннями типів, а `===` вимагає збігу типу та значення. Наявність `===` у JavaScript не робить усі правила порівняння цих мов тотожними. Для PHP особливо важливо враховувати версію: правила деяких нестрогих порівнянь змінювалися. Приклади теми орієнтовані на PHP 8.1+, відповідно до вимоги навчального Laravel-проєкту.

```php
<?php
$count = 3;
$input = '3';
var_dump($count == $input);  // true
var_dump($count === $input); // false
for ($i = 0; $i < $count; $i++) {
    echo 'Курс ' . ($i + 1) . PHP_EOL;
}
```

Оператор `.` у PHP об'єднує рядки. Звичка застосовувати `+` для тексту після JavaScript або Java призводить до помилок: у PHP це арифметичний оператор. Дужки навколо `$i + 1` явно показують порядок дій. Під час читання незнайомого виразу слід перевіряти не лише назви операторів, а й їхній пріоритет та допустимі операнди.

Області видимості також відрізняються. Звичайний блок `if` у PHP не створює окремої області видимості змінних, а функція має власну локальну область. У JavaScript оголошення через `let` і `const` мають блочну область. Тому переміщення змінної всередину дужок саме по собі не забезпечує в PHP її ізоляцію від решти функції.

Масив PHP може поєднувати цілочислові та рядкові ключі. Його не слід автоматично ототожнювати з масивом фіксованого розміру в C або типізованим масивом Java. Аналогічно доступ до властивості об'єкта в PHP записують через `->`, а статичний доступ — через `::`. Порівнювати мови корисно за конкретною операцією, а не за враженням від схожості коду.

## Завдання

1. Складіть таблицю для всіх шести мов: блок, змінна, цикл, коментар, об'єднання рядків.
2. Перед запуском прикладу передбачте кожен рядок виведення, потім зіставте прогноз із результатом.
3. Поясніть три помилки перенесення коду: `+` для рядків, нестроге порівняння та припущення про блочну область PHP.

## Вимоги до результату

Подайте таблицю, результат виконання та пояснення відмінностей. Для обраної мови порівняння додайте посилання на її офіційний довідник. Відокремте синтаксичну помилку від правильного запису з неочікуваною поведінкою.
