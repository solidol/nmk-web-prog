## Використання матеріалів

Кожна тема містить 3000–4000 знаків із пробілами, включно із заголовками, кодом, посиланнями та джерелами у Markdown. Переноси рядків під час підрахунку нормалізовано до LF. Завдання й вимоги до подання є методичними вказівками до цих матеріалів.
