1. Мови формування вебсторінок. Python — 2 год.
2. Спорідненість синтаксису PHP з мовами C, C++, C#, Java, JavaScript — 2 год.
3. Використання циклів у мові PHP — 2 год.

5. Суперглобальні масиви $_GET, $_POST, $_SERVER — 2 год.
6. Змінні оточення вебсервера — 2 год.
7. Копіювання та переміщення файлів — 2 год.
8. Засоби PHP для роботи з СУБД PostgreSQL — 2 год.
9. Формат передачі даних JSON — 2 год.
10. Стандартний клас — 2 год.
11. Конструктори класів — 2 год.
12. Інкапсуляція та поліморфізм — 2 год.
13. Абстрактні класи та інтерфейси — 2 год.
14. Створення бібліотеки функцій на основі класів зі статичними методами — 2 год.
15. Шаблонізатор TPL — 2 год.
16. Шаблонізатор TWIG — 2 год.
17. Структура фреймворку Laravel — 2 год.
18. Архітектура MVC у фреймворку Laravel — 1 год.
