# Використання циклів у мові PHP

## Мета

Обирати цикл відповідно до структури даних і умови завершення, перевіряти граничні випадки та пояснювати результат обходу. Самостійна робота — 2 год.

## Теоретичний матеріал

Цикл повторює дії, доки виконується задана умова або залишаються елементи для обходу. У вебзастосунку це формування списку курсів, обчислення підсумків або оброблення записів. Перед написанням циклу визначають початковий стан, зміну стану на кожному кроці та умову зупинки. Якщо жодна дія не наближає завершення, програма може витратити доступний час виконання.

Цикл `for` зручний, коли потрібен лічильник. Його заголовок містить ініціалізацію, умову продовження та зміну лічильника. Для індексів від нуля до кількості елементів мінус один використовують умову `<`, а не `<=`. Помилка на одиницю проявляється пропуском першого чи останнього елемента або зверненням за межі набору.

Цикл `while` перевіряє умову перед кожною ітерацією і може не виконатися жодного разу. `do ... while` перевіряє її після тіла, тому має щонайменше одну ітерацію. Ця відмінність важлива для порожнього результату: не можна обробляти неіснуючий запис лише тому, що обрано цикл із післяумовою. Вид циклу має відповідати логіці задачі.

Для масивів часто доцільний `foreach`: він послідовно надає значення, а за потреби — ключ і значення. Це зручніше за припущення, що всі ключі є неперервними числами. У PHP масив може містити рядкові ключі, тому збільшення числового індексу не є універсальним способом його обходу.

```php
<?php
$hours = ['PHP' => 6, 'MariaDB' => 0, 'Laravel' => 4];
$total = 0;
foreach ($hours as $topic => $value) {
    if ($value === 0) {
        continue;
    }
    $total += $value;
    echo $topic . ': ' . $value . PHP_EOL;
}
echo 'Разом: ' . $total . PHP_EOL;
```

Це умовні дані для алгоритму, а не розподіл годин дисципліни. `continue` пропускає решту поточної ітерації, після чого обхід триває. `break` завершує цикл. Для прикладу підсумок становить 10. Якщо замінити `continue` на `break`, оброблення закінчиться на нульовому значенні, і Laravel до суми не потрапить. Отже, ці оператори не взаємозамінні.

Під час `foreach` за посиланням змінна може залишатися пов'язаною з останнім елементом після циклу. Якщо такий спосіб справді потрібний, зв'язок розривають через `unset()`; для звичайного читання обходять за значенням. Вкладені цикли також потребують уваги: порівняння кожного запису з кожним іншим швидко збільшує кількість операцій.

У вебсторінці назви, отримані від користувача, екранують під час HTML-виведення. Великий набір записів доцільно обробляти частинами. Запит до бази даних на кожній ітерації може стати причиною зайвих звернень; спочатку слід з'ясувати, чи можна отримати потрібні дані одним підготовленим запитом.

## Завдання

1. Виконайте приклад і поясніть зміну результату після заміни `continue` на `break`.
2. Побудуйте таблицю трасування: ключ, значення, сума після ітерації.
3. Перевірте порожній масив, один елемент та набір із самих нулів. Обґрунтуйте вибір циклу для кожного випадку.

## Вимоги до результату

Подайте код, таблицю трасування і результати трьох граничних перевірок. Поясніть, чому програма завершується та як уникнуто звернення до відсутнього елемента.
