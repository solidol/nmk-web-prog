# Редакторські уточнення до лабораторної роботи №14

## Зафіксовано

PHP 8.1, PDO та MariaDB; OSPanel 6+ — основне середовище, XAMPP із PHP 8.1 — альтернатива. Структура app/models, app/views, app/config і public/index.php; всі підключення виконує index.php. Окремих контролерів і шаблонізатора немає.

## Потребує уточнення

- [ ] Уточнити версію, хост і порт MariaDB в навчальному середовищі.
- [ ] Перевірити pdo_mysql, mbstring та доступність змінних середовища для вебпроцесу й CLI.
- [ ] Узгодити використання перевірки входу з попереднього студентського проєкту для самостійного редагування й видалення.
