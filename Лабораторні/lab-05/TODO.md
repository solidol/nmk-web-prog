# Редакторські уточнення до лабораторної роботи №5

Цей файл призначено для супроводу матеріалів викладачем. Навчальні завдання наведено в [README.md](README.md).

## Потребує уточнення

- [ ] Уточнити фактичну версію PHP, який використовує Apache у навчальному середовищі.
- [ ] Звірити доступність mbstring та ліміти завантаження файлів із середовищем виконання.
