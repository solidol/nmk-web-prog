# Редакторські уточнення до лабораторної роботи №10

Цей файл призначено для супроводу матеріалів викладачем. Навчальні завдання наведено в [README.md](README.md).

## Потребує уточнення

- [ ] Уточнити фактичні версії PHP й Postman у навчальному середовищі та доступність mbstring, ctype, fileinfo.
- [ ] Підтвердити режим роботи Postman і доступність Collections, Environments, Scripts та Collection Runner для навчальних облікових записів.
- [ ] Звірити шлях тимчасового сховища між CLI й Apache та права читання/запису.
- [ ] Перевірити доступність тимчасового каталогу PHP для тіла запиту й вкладень та журналювання без діагностики в JSON-відповідях.
- [ ] Перевірити старі додаткові посилання QAGroup і Highload.today, якщо їх планується використовувати в навчанні.
- [ ] За потреби підготувати нові знімки інтерфейсу Postman замість архівних GIF.
