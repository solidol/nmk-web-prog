# Редакторські уточнення до лабораторної роботи №11

## Зафіксовано

PHP 8.1, основне середовище — OSPanel 6+, альтернатива — XAMPP із PHP 8.1. Сервер — MariaDB; класичний доступ до даних — процедурний MySQLi, адміністрування — phpMyAdmin.

## Потребує уточнення

- [ ] Уточнити версії MariaDB і phpMyAdmin на навчальних комп’ютерах.
- [ ] Звірити хост, порт, доступність mysqli/mbstring та налаштування змінних середовища для вебпроцесу й CLI.
- [ ] Узгодити окремі навчальні бази й користувачів без публікації реальних реквізитів.
