# Редакторські уточнення до лабораторної роботи №2

Цей файл призначено для супроводу матеріалів викладачем. Навчальні завдання наведено в [README.md](README.md).

## Потребує уточнення

- [ ] Уточнити версію Apache та доступність CGI у навчальному середовищі.
- [ ] Уточнити версії інструментів для демонстрацій CGI.
- [ ] Перевірити відносні посилання на приклади: у README.md використано шляхи src/lab-02/, які потребують звірки з фактичним розміщенням файлів.
