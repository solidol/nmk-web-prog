# Редакторські уточнення до лабораторної роботи №9

Цей файл призначено для супроводу матеріалів викладачем. Навчальні завдання наведено в [README.md](README.md).

## Потребує уточнення

- [ ] Уточнити фактичну версію PHP вебсервера та CLI в навчальному середовищі.
- [ ] Підтвердити доступність GD, PNG і FreeType на навчальних комп’ютерах.
- [ ] Узгодити доступний TrueType-шрифт із підтримкою української та умови його розповсюдження.
- [ ] Перевірити актуальність збереженого додаткового посилання PHP.su.
