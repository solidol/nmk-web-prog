# Навчальне середовище дисципліни «Web-програмування»

## Зафіксовані вимоги

- Екосистема розробки — PHP.
- Навчальна версія — **PHP 8.1**. Приклади мають бути сумісними саме з цією версією.
- Основне середовище — **OSPanel 6+** з вибраним модулем PHP 8.1.
- Альтернатива для студентів — **XAMPP** із PHP 8.1. Наявність іншої версії PHP у пакеті не змінює навчальної вимоги.
- У ЛР 1–10 серверні приклади виконуються на чистому PHP. Фреймворк вводиться лише в роботах, де це прямо зазначено.

Це узгоджені вимоги курсу, а не припущення щодо програм, установлених на конкретному комп’ютері. Фактичну версію перевіряйте окремо для вебсервера й термінала.

## Запуск в OSPanel

1. Установіть OSPanel 6+ та виберіть для навчального проєкту PHP 8.1.
2. Створіть локальний проєкт і домен, наприклад `web-prog.local`, задайте публічний каталог. Налаштування проєктів і назви параметрів залежать від редакції OSPanel; користуйтеся документацією саме встановленої версії.
3. Розміщуйте кожну роботу в окремому каталозі `lab-XX`. Для робіт із непублічним сховищем дотримуйтеся вимоги щодо кореня вебсервера в самій роботі.
4. Запускайте PHP-команди з консолі з активованим середовищем проєкту OSPanel. Перевірте `php -v`: потрібна гілка 8.1. У браузері перевірте PHP через тимчасову сторінку `phpinfo()`, після чого приберіть її.
5. Увімкніть потрібні розширення в конфігурації вибраного модуля PHP. Не орієнтуйтеся на `php.ini` іншого середовища.

## Відповідність шляхів для альтернативного XAMPP

| Налаштування | OSPanel 6+ | XAMPP |
| --- | --- | --- |
| Каталог роботи | Публічний каталог проєкту, підкаталог `lab-XX` | `C:\xampp\htdocs\lab-XX` за типової інсталяції |
| Адреса | `http://web-prog.local/lab-XX/` для наведеного прикладу домену | `http://localhost/lab-XX/` |
| Команда PHP | `php` у середовищі проєкту з PHP 8.1 | Власний `php.exe` пакета з PHP 8.1 |
| Перевірка налаштувань | Конфігурація вибраного PHP-модуля | Фактично завантажений `php.ini` |

Абсолютний шлях інсталяції й локальний домен студент визначає за своїм середовищем. Адреси `web-prog.local` у матеріалах — приклад: замінюйте їх фактично налаштованим доменом. Шляхи `C:\xampp\...` та адреси `localhost` використовуються для альтернативного XAMPP.

У ЛР 7 збережіть URL-шлях `/lab-07/` або узгоджено змініть `COOKIE_PATH` у всіх операціях. У ЛР 10 змініть `base_url` середовища Postman на фактичну адресу API. Для ЛР 6 корінь вебсервера має бути `src`, щоб сусідній каталог `storage` не був доступний через HTTP.

Вбудований сервер `php -S` — додатковий спосіб запуску прикладів тим самим PHP 8.1, а не інша версія технологічного стеку. Не очищуйте спільні каталоги проєктів і не запускайте обидва середовища на одному зайнятому порту.
