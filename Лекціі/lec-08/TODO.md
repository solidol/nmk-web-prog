# Редакторські уточнення до лекції №8

## Зафіксовано

PHP 8.1; OSPanel 6+ як основне середовище, XAMPP із PHP 8.1 як альтернатива. Доступ до MariaDB у матеріалах лекції — лише через MySQLi.

## Потребує уточнення

- [ ] Уточнити навчальну версію модуля MariaDB та його хост і порт.
- [ ] Підтвердити наявність mysqli та mbstring у PHP 8.1 навчального середовища.
- [ ] Підготувати окрему навчальну базу й користувача з правами SELECT, INSERT, UPDATE, DELETE; створення структури виконати під час підготовки.
