# Редакторські уточнення до лекції №9

## Зафіксовано

PHP 8.1; OSPanel 6+ як основне середовище, XAMPP із PHP 8.1 як альтернатива. У лекції використано PDO та pdo_mysql для MariaDB і MySQL.

## Потребує уточнення

- [ ] Узгодити версії MariaDB/MySQL у навчальному середовищі та параметри модулів.
- [ ] Перевірити доступність pdo_mysql для вебпроцесу й CLI.
- [ ] Підготувати окрему навчальну базу та користувача з правами SELECT, INSERT, UPDATE, DELETE.
